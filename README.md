## 🎯 Overview
**AI-Network-Anomaly-Detector** is an advanced machine learning-based security tool designed to monitor network traffic patterns and identify abnormal behaviors or hidden cyber threats. By establishing a baseline of normal traffic, it flags deviations that may indicate network intrusions, malware communications, or scanning activities.

---

## ✨ Key Features
- **Traffic Pattern Analysis:** Monitors packet flows and network metrics to detect unexpected behaviors.
- **Machine Learning Detection:** Utilizes unsupervised and supervised models to spot anomalies without relying solely on static signatures.
- **Real-time Alerting:** Triggers immediate warnings when abnormal network activity thresholds are breached.
- **Flexible Data Input:** Compatible with PCAP files or live network stream capture logs.
